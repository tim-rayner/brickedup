# Top sets: free-text entry for v1

Onboarding offers optional top sets without a set catalog or barcode scanner yet.

**Decision:** For v1, members enter top sets as free-text **set number** + **name** (`source: manual`, barcode/image optional nulls). No curated picker or live Rebrickable integration in this pass. Barcode-first and catalog typeahead remain future upgrades; the Profile top-set shape stays unchanged.

**Why:** Keeps the skippable AFOL signal in first-run without blocking on catalog ingestion or third-party API keys.
